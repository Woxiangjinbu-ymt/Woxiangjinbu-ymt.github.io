# 求职与成长

这里记录可以公开分享的求职经验、学习选择和阶段性复盘。

## 公开边界

本站不保存包含电话、住址、证件信息的完整简历，也不保存未公开投稿、内部面试材料或受保密约束的内容。私人材料始终留在独立的私有空间。

## 内容结构

- **简历与面经**：只发布经过脱敏和重新整理的经验。
- **阶段性复盘**：记录目标、行动、结果和下一阶段调整。
