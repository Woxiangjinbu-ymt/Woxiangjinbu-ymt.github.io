# 算法与数据结构

这里不以题号堆积答案，而是按问题模式整理可复用的思考框架。

## 内容结构

- **LeetCode Hot 100**：高频经典题的系统训练。
- **面试 150**：围绕面试场景补齐算法覆盖面。
- **专题突破**：双指针、动态规划、图、回溯、二分、链表、树和堆。
- **竞赛笔记**：记录时间限制下的判断、失误和复盘。

## 记录原则

每篇笔记至少回答三个问题：为什么能识别出这个模式、核心不变量是什么、复杂度如何推导。题目代码保存在独立代码仓库中，本站只保留解释和固定版本链接。
