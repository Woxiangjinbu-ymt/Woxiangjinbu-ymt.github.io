- **语言与工具**：Python、Go、Git、Linux 与 Docker。
- **CS 基础**：操作系统、网络、数据库和系统设计。
- **MLSys & LLM 工程**：训练、微调、推理部署、RAG 与 Agent Framework。
- **项目实战**：记录真实项目中的选择、权衡、故障和复盘。

笔记优先解释机制和边界，再给出能够复现的最小示例。
