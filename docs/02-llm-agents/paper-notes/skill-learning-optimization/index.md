# Skill Learning & Optimization

这个主题关注 Agent 如何从经验、示例或环境反馈中形成可复用技能，并在新任务上选择、组合和改进这些技能。

## 当前问题框架

1. **技能是什么**：提示片段、程序、工具策略、轨迹摘要，还是可训练参数？
2. **技能从哪里来**：人工编写、成功轨迹抽取、自我改进或强化学习？
3. **怎样判断技能有效**：成功率、泛化、成本、稳定性与可解释性如何权衡？
4. **怎样优化技能库**：新增、合并、淘汰、检索和组合分别需要什么信号？
